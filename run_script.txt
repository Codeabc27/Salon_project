# Salon Platform System – Run Script

## Prerequisites
- Python installed
- Node.js and npm installed
- `uv` Python package manager

## 1. Backend Setup and Run

Open Terminal 1 (Backend) in the project root directory.

### Step 1: Install uv
```bash
pip install uv
```

### Step 2: Install backend dependencies
```bash
uv sync
```

### Step 3: Start the backend server
```bash
uv run uvicorn main:app --reload
```

**Note:** This assumes the FastAPI application is defined as `app` in `main.py`. If your backend entry-point file has a different name or is inside a subfolder, update the command accordingly.

Backend URL: http://127.0.0.1:8000

API documentation: http://127.0.0.1:8000/docs

## 2. Frontend Setup and Run

Open Terminal 2 (Frontend) in the frontend directory.

### Step 1: Install frontend dependencies
```bash
npm install
```

### Step 2: Start the frontend development server
```bash
npm run dev
```

Frontend URL: Check the terminal output. Vite typically uses http://localhost:5173.

## 3. Important Notes
- Keep both terminals running while using the application.
- Ensure the frontend API URL points to the backend URL.
- Run `uv sync` from the directory containing `pyproject.toml`.
- Run `npm install` from the directory containing `package.json`.
- Never commit `.env` files containing passwords, API keys, or other secrets to GitHub.

## 4. Quick Start Summary

Backend:
```bash
pip install uv
uv sync
uv run uvicorn main:app --reload
```

Frontend:
```bash
npm install
npm run dev
```
